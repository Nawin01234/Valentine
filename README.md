# 💕 Valentine's Day Web App

เว็บไซต์สำหรับวันวาเลนไทน์สุดน่ารัก!

## 📋 รายละเอียด

เว็บนี้เป็นเว็บไซต์แบบ interactive สำหรับวันวาเลนไทน์ ประกอบด้วย:

- **หน้า 1:** หน้าต้อนรับพร้อม countdown
- **หน้า 2:** คำถาม "Can you be my Valentine?" พร้อมปุ่ม Yes/No (ปุ่ม No จะหนีเมาส์!)
- **หน้า 3:** หน้าผลลัพธ์เซอร์ไพรส์

## 🚀 วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. รอ countdown หน้าแรก
3. ลองกดปุ่ม!


## 💖 สร้างด้วยความรักของนาวินทั้งใจนะจ๊ะ

Happy Valentine's Day! 🌹
